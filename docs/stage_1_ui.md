# Stage 1：可操作的 2D 界面

主场景为 scenes/main.tscn，在 Godot 按 F6 运行主场景或 F5 运行项目。默认随机游玩。鼠标点击开始、抛竿、收竿、继续和重开；按钮也支持键盘焦点操作。

## 职责

GameController 只连接输入与模型、处理短暂抛竿动画锁、将结算传给视图。GameView 显示快照并发出请求，不计算收入或决定胜负。FishingView 只绘制海面和船的简单 2D 动画。三个展示类不改变既有领域算法。

画面包含菜单规则、天数、船租、金币、鱼饵、网兜重量与每条鱼、渔获反馈、每日结算和胜负结果。结束后自动结算，成功可继续，失败或通关只能重开。任一结算页也可重开一局。抛竿表现期间锁定输入，领域规则继续负责状态合法性。

GameController.catch_source_factory 是可选的组合入口，供测试/演示提供可复现渔获；正常为空，使用 RandomCatchSource。固定来源仅存在测试目录，正式场景不依赖测试文件。所有规则保持在 domain 下，视图只进行字符串格式化及展示。

## 验证

tests/test_ui.gd 实例化实际主场景，触发真实按钮连接，覆盖开始、动画中连点、收竿、七天通关、继续、胜利后重开、爆网自动结算和空网失败。原有领域测试仍需全部通过。
